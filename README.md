ESP Light Controller 🌐💡

A web-based ESP Light Controller project built using Arduino (.ino) and HTML. It allows users to control ESP-connected lights through a web interface that can be accessed remotely over the internet using a public GitHub-hosted domain, without requiring the user and the ESP device to be connected to the same Wi-Fi network.

Developed collaboratively with my partner Abdul Khalique, this project combines embedded systems and web technologies to make light control simple, convenient, and accessible from anywhere with an internet connection.

Technologies Used: Arduino, ESP, C++ (.ino), HTML, and GitHub.

Key Features:

💡 Web-based light control interface
🌍 Remote access over the internet
📱 Accessible from different devices
🔌 ESP-based hardware integration
🤝 Collaborative development with Abdul Khalique

Goal: To build a simple and accessible IoT-based lighting control system that enables remote operation without depending on a shared local Wi-Fi network.
